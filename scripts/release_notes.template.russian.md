## Market Monitor — Desktop GUI {{version}}

Портативная сборка для **Windows 10/11 x64**. Python устанавливать не нужно.

### Что скачать
`{{asset}}` — распакуйте архив целиком в любую папку и запустите
`MarketMonitor\MarketMonitor.exe` (запускайте именно из папки: рядом лежат файлы,
которые нужны приложению).

### Первый запуск
1. Запустите `MarketMonitor.exe`.
2. Откройте **«Настройки»** и укажите адрес API (по умолчанию
   `https://api.market-resale-signal.xubi.org`).
3. Там же введите общий секрет приложения (APP_SECRET) и сохраните — он хранится только
   на этом компьютере, в зашифрованном виде (`%LOCALAPPDATA%\market-monitor-gui`).
4. Подключитесь и проверьте раздел **«Обзор»**.

Секрет **не входит** в сборку и не передаётся вместе с ней.

### SmartScreen и антивирус
Сборка не подписана. Windows может показать «Windows защитил ваш компьютер»:
нажмите **«Подробнее» → «Выполнить в любом случае»**. Некоторые антивирусы могут
предупредить о неизвестном приложении — сборка собрана автоматически из исходного кода
в GitHub Actions.

### Если приложение не запускается
- `MarketMonitor.exe --version` печатает версию — так можно проверить, что файл цел.
- Если Windows сообщает об отсутствии `VCRUNTIME140.dll`, установите
  «Microsoft Visual C++ 2015–2022 Redistributable (x64)».
